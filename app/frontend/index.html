留空则自动检测本机已安装的多模态模型；没有可用模型时会按原文位置标注图片，不丢图。
每次审查完成后自动保存；再次打开同一文件会直接载入，不重复调用模型。
不同类型笔记值得关心的东西不同：论文重引用与定义，会议记录重行动项与人名，技术笔记重 API 与版本号。
轻：只挑错别字与事实错误；标准：兼顾表达；严格：连措辞一起优化，并主动补充缺失知识。
专有名词、自造缩写、团队内部叫法写在这里，模型不会去「纠正」它们。导入/导出是一行一个词的 txt，方便多台机器共用。
并发只在服务端支持并行时才会变快（Ollama 可设 OLLAMA_NUM_PARALLEL=3）；不确定就用 1。每段上限用来压掉「同一段挑出十几条小事」的噪声。
点「运行自检」检查模型服务、图像理解、ffmpeg、语音转写、磁盘与历史目录是否就绪。
换电脑或重装时用它搬设置。导出的 JSON 不含 API Key，导入时也不会用空值覆盖你已填的密钥。
